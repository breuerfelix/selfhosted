# Phoenix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy authenticated Phoenix and an authenticated JSON-to-protobuf trace collector on Hetzner.

**Architecture:** One Phoenix SQLite deployment and one collector, using existing Flux, Traefik, cert-manager, SOPS-age, and retained hostPath storage.

**Tech Stack:** Kubernetes plain manifests, Kustomize, Ansible, Phoenix 22.0.1, OpenTelemetry Collector Contrib 0.165.0.

**Spec:** `docs/superpowers/specs/2026-11-22-phoenix-design.md`

## Global Constraints

One replica each; traces only; no multi-node scheduling, extra services, custom application code, or ad hoc backups. Preserve existing paths and ownership. Never print or commit plaintext credentials. Pin images by release and digest.

## Review Focus

Missing/wrong bearer tokens must fail. Default admin credentials must fail. Collector accepts JSON and Phoenix persists protobuf traces. Existing host data remains untouched. Restarts preserve SQLite and authentication secrets.

## Steps

- [x] Create `hetzner/cluster/apps/phoenix/{app.yaml,collector.yaml,collector-config.yaml,ingress.yaml,storage.yaml,kustomization.yaml,secrets.sops.yaml}`; register the app and add create-if-absent Ansible storage preparation. Generate credentials in memory and encrypt directly through SOPS.
- [x] Build Kustomize, syntax-check Ansible, validate collector configuration using the pinned image, and server-dry-run decrypted resources without printing secrets. Review the diff against the spec.
- [ ] Prepare `/data/phoenix` through Ansible, commit/push reviewed changes to `main`, and reconcile Flux. Check deployment, PVC, certificate, HTTPS, and authentication readiness.
- [ ] Send a unique synthetic JSON trace through public ingestion, verify it via Phoenix, restart Phoenix, and verify it remains. Check missing/wrong tokens and default login rejection; do not send a paid OpenRouter request without credentials and configuration.
- [ ] Add `hetzner/docs/phoenix.md` with secure credential retrieval and exact per-workspace OpenRouter instructions; update the app/storage documentation and report verified results and remaining manual steps.
